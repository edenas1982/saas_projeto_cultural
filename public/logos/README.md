# Logos

Este diretório armazena as imagens de apoio cultural e institucional exibidas na Landing Page.

Faça o upload (envio) das imagens para esta pasta com os seguintes nomes para que apareçam automaticamente na página inicial:

- `snc.png` - Sistema Nacional de Cultura
- `aldir-blanc.png` - Política Nacional Aldir Blanc
- `minc-brasil.png` - Ministério da Cultura (Governo do Brasil)
- `prefeitura.png` - Prefeitura Municipal de Santo Augusto
- `secute.png` - SECUTE (Secretaria Municipal de Cultura, Turismo e Esporte)

> **Dica:** Caso suas imagens originais estejam em `.jpg` ou outras extensões, certifique-se de renomear as chamadas no arquivo `src/pages/LandingPage.tsx` ou convertê-las para `.png` com fundo transparente.
